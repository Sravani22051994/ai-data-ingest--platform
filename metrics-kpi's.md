# Metrics & KPI Framework  
## AI-powered Data Ingestion Platform

---

# 1. North Star Metric

**Time to First Successful Ingestion (TTFSI)**  
Time from dataset upload to validated, accepted output delivered downstream.

---

# 2. Activation Metrics

- First-pass validation success rate
- Mapping accuracy rate
- Auto-suggestion acceptance rate
- Routing accuracy rate

---

# 3. Efficiency Metrics

- Average processing time per job
- Manual intervention rate
- Error correction cycle time
- Configuration time per tenant

---

# 4. Quality Metrics

- Anomaly detection precision
- False positive rate
- Schema drift detection rate
- Output contract compliance rate

---

# 5. Business Impact Metrics

- Tenant onboarding time reduction
- Operational hours saved
- Support ticket reduction
- Revenue acceleration from faster onboarding

---

# 6. Guardrail Metrics

- AI confidence score distribution
- Override frequency
- Model performance degradation over time
- SLA adherence

---

# 7. Measurement Philosophy

- Prioritize first-pass success
- Optimize for reduced friction
- Maintain governance and explainability
- Balance automation with reliability
